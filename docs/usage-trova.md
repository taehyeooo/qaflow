# Trova에서의 사용 기록

## 왜 만들었나 (실측)
한 Claude Code 세션(2026-09-25 ~ 10-07)에서 손으로 한 QA 작업: API 직접 호출 143번, 테스트 데이터 직접 삭제 54번,
처리 완료 기다리기 38번, QA 토큰 만들기 38번, 실패 원인 조회 16번, 데이터 직접 넣기·공유 링크 붙여넣기 각 11번.
같은 "공유 → 자동 초안 → 여행" 흐름을 하루(10/7)에 손으로 4번 확인했다.

## 첫 실사용 (2026-10-07 18:53, 로컬 서버 + 개발 DB, iPhone SE)
| 무엇 | 결과 |
|---|---|
| `qa-api default` | 로컬 API 8개 통과(1초), 테스트 토큰 자동 생성 |
| `qa-api prod-public` | 운영 인증 없는 확인 3개 통과 |
| `qa-data snapshot` | 13개 테이블 기준 저장 |
| `qa-scenario run share-to-trip` | 13단계 **52초**(손 탭 0번): 공유 → 분석 → 백그라운드 → 초안 READY → 다시 열기 → 홈 카드 → 초안 → 여행 |
| `qa-data cleanup` | QA로 생긴 6행만 삭제(초안·여행 장소·일차·여행·영상 장소·작업), 13개 테이블 개수 기준과 같음 |
| `qa-env stop` | QA 한 번 73초, 탭 6번, 남은 패치 0건 |

만들면서 고친 것: 인증 없는 묶음에서 빈 헤더 배열 오류, 사용량 명령의 따옴표가 한 번 더 감싸진 문제.
